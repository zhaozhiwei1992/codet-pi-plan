# AGENTS.md — 全局工作纪律（codet-pi-plan 推荐全局版）

> 放到全局 AGENTS.md（Pi: `~/.config/pi/agent/AGENTS.md`）。
> 适用于所有项目与所有非项目会话。项目特定的约定放各自项目根目录的 AGENTS.md。

## 选择性规划（Selective Planning）

动手做有实际影响的改动之前，先判断规模，决定是否先出计划：

- 🚩 **先规划再动手**（先在回复里列清楚方案，或对项目级改动生成 `PLAN-<slug>.md`）：
  - 跨多个文件 / 模块的改动
  - 涉及核心逻辑、数据迁移、依赖升级、接口契约变更
  - 影响面不明、可能破坏现有行为
  - 用户明确说"先规划一下" / "计划一下"
- ⚡ **直接做**（无需计划）：
  - 单文件小改动：修 bug、加小功能、改样式、改文案、调整参数
  - 纯问答、查资料、解释代码、生成一次性脚本
  - 目标明确、风险低、路径清晰

规划不等于必须落盘文件：
- **项目内变更**（cwd 在 git 项目里）→ 可以写 `PLAN-<slug>.md` 到项目根并进入 PLAN 状态逐步执行
- **非项目工作**（临时脚本、一次性任务、全局配置调整）→ 在对话里先列方案、征得确认后再动手，**通常不落盘 PLAN 文件**，避免污染目录

## 执行纪律

- 改动前先理解现状，不要臆测；涉及不熟悉的代码先读再看
- 宁可先问清楚再动手，不要按错误理解做大规模改动
- 做完跑相关验证（测试 / lint / 构建）再收尾
